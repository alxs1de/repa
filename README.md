# Предусловия для запуска: Нужно иметь программу для тестирование/просмотра кода (К примеру: PyCharm, VSCode с Pytest) и Allure.

# Условия для запуска: В терминале, написать комманду 'allure serve allure-result'. Откроется окно с результатами и информацией о тестах от Allure.

# Как завершить тест: Закрыть вкладку с тестами от Allure, нажать Ctrl C, затем написать y в консоли и нажать Enter.
